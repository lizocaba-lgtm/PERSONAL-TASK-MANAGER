## About this project
A simple task management system built with Laravel following the MVC pattern.
- Model:`Task` — handles task data
- Controller:`TaskController` — manages all logic
- Routes: RESTful resource routes
- Views:Blade templates with custom CSS styling
- Database: SQLite for data storage
